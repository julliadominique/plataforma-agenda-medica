# Código de Conduta

## Nosso Compromisso
Nos comprometemos a tornar a participação no projeto **HealthConnect** uma experiência livre de assédio para todos, independentemente de idade, etnia, identidade de gênero ou nível de experiência.

## Nossos Padrões
Exemplos de comportamento positivo incluem usar linguagem empática, respeitar opiniões divergentes e aceitar críticas construtivas.
